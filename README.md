# 恐龙行动：横版 ACT

四个章节统一采用房间式推进。每章有独立的 10 个手工房间模板和 10 套短过渡地形；第一章固定经过 4 个房间，首间地形固定，保持教学节奏，其余章节每局经过 4～5 个不重复房间。完成房间路线后进入安静的 Boss 前庭、本章 Boss 房和章节间营地。房间按用途分为战斗模块和事件模块；四章各自预留事件房定义，布局、完成条件和状态入口独立于战斗模块，目前关闭，不会出现在游戏中。

| 章节 | 房间玩法主题 |
| --- | --- |
| 晨雾湿地 | 平缓苇滩、浅溪和可选沉木平台，较简单的教学敌人组合 |
| 风蚀峡谷 | 坡顶、低谷、断桥和双层岩廊，沿用峡谷房间池 |
| 巨木秘境 | 上下层路线、可走出的根底区域、横移／升降／坠落平台、弹性蘑菇；高台远程与地面战斗结合 |
| 熔火遗迹 | 熔岩短裂隙、陡坡、喷发／落石预警、热流及可恢复崩塌平台；危险区域减少敌人堆叠 |

战斗房间分为普通房间（恰好两个独立战场）和高难度房间（恰好三个独立战场）。普通房间的通关奖励只使用战技、骨片、鸡腿；高难度房间的通关奖励只使用进化特质、原始形态。敌人掉落和 Boss、商人、章节间营地原有奖励保持各自规则。全部敌人在进入房间时已经存在并可见，按距离自然索敌；战场之间没有推进门、能量屏障或强制清理顺序，玩家可以自由穿行和回头。仅奖励出口受约束：所有必要敌人清理完成并领取房间奖励后，出口才可使用。入口、过渡、坡道、低谷、双层路线、断岩桥、升降浮石和环境战斗采用手工坐标配置。敌人由预设组合池抽取，第二场与第一场使用不同组合。

主要战场间的过渡段长 360 个关卡单位。过渡地形按章节独立抽取，相邻房间不会连续选到同一种过渡段；第一章使用平缓湿地过渡，第三章使用树根、藤架和双层通路，第四章部分过渡带有可跳越的熔岩裂隙。相同 Seed 可以复现组合。每段过渡有 65% 概率出现一次性补给；其中 70% 为回复 2 HP 的食物，30% 为骨刺能量补满。无需先清理战场即可取用，对应资源已满时不会消耗。高难房间第三战场前的短过渡也参与补给随机。概率位于 `ChapterRoomTuning`，回血量沿用 `ActRewardTuning.HealAmount`，过渡地形与补给位置位于 `desktop/ActRoomTransitions.cs`。

出口大厅通常有两个奖励门，少量房间有三个；奖励门分布在地面、高台和低谷，前两扇门水平相隔 580 个关卡单位、高低相差 200，第三扇门与高台相差 280。上下层由可步行斜坡连接，也有可选跳台捷径，基础能力即可到达。高难奖励门占全部随机奖励门的约 20%，即高难与普通约 1:4；每个大厅至少有一个普通门、最多一个高难门，不再每个房间必定提供高难门。两个门的大厅有 40% 概率包含一个高难门，三个门为 60%；实际经过多少高难房间由玩家选门决定。概率由 `ChapterRoomTuning.HardExitShare` 配置。门上显示奖励和必要战斗数量。进化、形态门通向高难房间，战技、骨片、鸡腿门通向普通房间，不再生成未知奖励门。站入其中一个门并停留 3 秒后进入下一房间。**门不直接给奖励：清理下一房间的全部必要战斗后才获得所选奖励。** 战技满槽沿用替换／放弃界面，形态库满时沿用普通进化奖励；普通进化已收集完可改发可用形态，两种成长均耗尽时仍正常开放出口。高难门带有 `!` 标记，不再额外发放骨片通关奖励。最后一个战斗房间只提供 Boss 前庭入口。

Boss 前庭固定刷新游商和骨片储藏，没有敌人或环境伤害，不能消耗战技。走近设施后按互动键（默认 E）使用：骨片储藏一次性提供 40 骨片，游商出售三个随机商品，复用原有购买、售罄和满槽替换规则。前庭不算章节间休息处，不会清除单地图异变或自动恢复生命。前庭出口停留 3 秒进入 Boss，HP、骨片和 Build 保留。位置和骨片数量集中在 `ChapterRoomTuning`。

从主界面“开始冒险”进入第一章教学房间；“地图调试”（默认 F10）选择任意一章可直接进入该章房间流程，“直接进入本章 Boss 场地”仍可使用。同一 Seed 与相同出口选择可复现四章房间、过渡、敌人和奖励组合；自然跨章继续使用本局 Seed，章节编号参与随机计算。房间内的 HP、战技、进化、形态、骨片和单地图异变持续保留；房间和 Boss 前庭切换不算进入新章节，不会重复触发跨地图回血或重置单地图异变。Boss 后进入营地才移除该章单地图异变，离开营地时激活下一章强化。

公共房间装配、峡谷模板和规则位于 `desktop/ActChapterRooms.cs`；湿地、巨木、熔火的模板、手工地形与敌人组合位于 `desktop/ActChapterRoomThemes.cs`，次数、出口概率与奖励数值集中在 `ChapterRoomTuning`。用途模块和奖励／难度规则位于 `desktop/ActRoomModules.cs`；以后添加事件房时，实现 `IChapterRoomModule` 的布局和完成判定，启用注册模块及所属章节的事件房定义，通过 `CompleteRoomEvent()` 完成事件，不需要创建虚假战斗。战斗模块继续检查所有必要战场。流程与延迟奖励位于 `desktop/ActRoomJourney.cs`，实体门和图标位于 `desktop/ActRoomJourneyVisual.cs`。`Run.RoomJourney` 保存 Seed、所属章节、房间深度、已走过的 RoomID、敌人组合记录、模块用途、普通／高难类别、事件完成状态及下一奖励，并在导出 RunState 时复制独立数据。旧连续地图生成器仅保留用于回归验证。

界面采用统一的冷灰半透明面板、像素细边框、暖金色选中态和白色图标，覆盖主界面、HUD、暂停／死亡／通关、奖励三选一、商店、形态库、按键设置和地图调试。公共绘制样式位于 `desktop/ActUiTheme.cs`。形态库先点击形态查看说明，再点击“使用此形态”确认；左右方向键可浏览。暂停菜单支持继续、设置、地图调试、重新开始及返回主菜单；后两项会结束当前一局。

本局最多携带 3 个原始形态，包含初始基础形态，即最多额外获得 2 个。形态库显示携带数量；库满后，新的形态奖励自动转为进化奖励。上限位于 `ActPrimalCatalog.FormCapacity`。奖励界面保留打开时的独立选项数据，领取后清空候选列表不会影响渐出动画。

## 战技与进化内容池

原有 8 个战技和 8 个进化保留。本轮增加 17 个战技、14 个普通进化、6 个稀有进化，总计 **25 个战技、22 个普通进化、6 个稀有进化**。战技仍然只有两个一次性槽位，允许携带重复战技；临时强化重复使用会刷新同类效果，不无限叠加。重复使用骨雨会分别安排两次落下，不相互覆盖。

| 新战技 | 默认效果 |
| --- | --- |
| 猎杀突进 | 0.58 秒高速无敌冲刺，沿途每个敌人只命中一次 |
| 霸王重击 | 下一次成功爪击 250% 伤害、强击退；挥空不消耗强化 |
| 尾骨震荡 | 立即扩大尾扫并击飞普通敌人 |
| 天降猛击 | 自动跃起、下坠、大范围落地冲击 |
| 骨雨 | 0.55 秒预警后，9 枚骨刺从屏幕上方落下 |
| 贯穿骨矛 | 大型高速骨矛，贯穿多个敌人 |
| 追猎骨刺 | 5 枚低伤害追踪骨刺 |
| 骨刺过载 | 5 秒免费骨刺，结束时能量清零 |
| 反击本能 | 4 秒内抵挡首次伤害并范围反击 |
| 血怒 | 失去 1 HP；8 秒近战伤害 ×1.6、攻速 ×1.35 |
| 捕食恢复 | 10 秒每击杀回复 0.5 HP，总回复上限 2 HP |
| 恐惧咆哮 | 普通敌人停止攻击并退避 2.5 秒，不控制 Boss |
| 残影狩猎 | 6 秒内冲刺结束留下延迟攻击的残影 |
| 原始屏障 | 5 秒内最多抵挡两次伤害 |
| 生命燃烧 | 失去 2 HP、补满骨刺、10 秒所有伤害 ×1.35 |
| 基因暴走 | 随机强化近战／骨刺／尾扫／下坠一项，持续 12 秒 |
| 紧急蜕变 | 刷新形态冷却、切换下一已拥有形态、5 秒伤害 ×1.25 |

生命消耗最低保留 1 HP。只有基础形态时，紧急蜕变依然刷新冷却并获得强化。HUD 显示临时效果名称、剩余时间及原始屏障次数。血怒、燃烧、过载、反击有身体光效；骨雨有落下提示，地面震波沿地形移动。残影和震波目前是程序绘制的基础表现，可继续替换美术资产。

普通进化新增：裂骨爪、猎食节奏、冲锋利爪、回旋尾、震荡尾骨、重力足骨、破地冲击、贯穿骨刺、碎裂骨刺、能量猎食、快速再生、危险本能、闪避猎手、适应性基因。猎食计数只用于内部效果，不添加 Combo UI。快速再生只在进入新战斗房／Boss 房且不足半血时触发一次，不会在前庭、营地或者重复重载同一房间时再次触发。

| 稀有进化 | 核心变化 |
| --- | --- |
| 无限骨髓 | 骨刺不耗能，骨刺伤害 ×0.7；能量为零也能射击 |
| 暴君血脉 | 近战范围扩大，第三击／尾扫／下坠追加震荡，骨刺伤害降低 |
| 捕食再生 | 每 5 个有效击杀回复 1 HP；同一敌人不会重复计数 |
| 极速适应 | 形态冷却 ×0.35，4 秒继承上一形态一项正面属性的 50% 加成 |
| 原始暴走 | HP≤2 时攻速／移速／伤害提高，受伤无敌时间缩短 |
| 骨骼增殖 | 骨刺有 35% 概率额外生成两枚小骨刺，兼容双生／穿透／碎裂 |

稀有进化**只能由 Boss 尸体上的进化奖励点获得**。普通房间、商人、营地进化设施、异变龙蛋、事件来源及形态满槽转化都使用普通池。每个进化具有 `Rarity` 和 `SourceRestriction`；`EligibleEvolutions` 负责筛选，`Run.AddEvolution(id, source)` 再验证获取来源，不能只改 UI 就绕过限制。

Boss 三选一默认抽取至少两个普通进化；第三位有 35% 概率为一张稀有进化，最终 Boss 为 65%。排除已拥有的进化。同局普通池不足时减少候选数、不重复填充，仍最多放一张稀有；普通进化全部拥有时，Boss 允许提供一个尚未拥有的稀有进化，避免奖励点卡住流程。普通来源池耗尽时不会转发稀有进化。

稀有卡片使用琥珀色双 DNA、双层亮边、独立暖色背景和轻微粒子，展开约 0.65 秒。选中后保留原有渐出动画，并播放短促原创合成音、金色粒子与 DNA 获得反馈；没有外部音频文件。普通卡片维持原有样式。全部 28 个进化图标都可鼠标悬停查看说明。

主要配置位于 `desktop/ActExpandedPowerCatalog.cs`：战技的 `Strength / Duration / Radius / Knockback / Projectiles / Speed / Delay / Cost / Pierce / SecondaryStrength`，进化的 `PowerModifier`，以及 `ActBuildTuning` 的 Boss 稀有概率、捕食回复、震波、碎片等参数。原有参数仍位于 `ActPowerCatalog.cs`、`ActTuning` 和 `ActCombatTuning`。

扩展新战技：增加 `BattleArtId`、目录数据，并在 `ActBuildEffects.RegisterExpandedArts` 注册处理函数。扩展进化：增加 `EvolutionId` 与目录中的修正数据；特殊命中／击杀／冲刺／形态切换效果接入 `ActBuildEffects` 的小型事件钩子，避免将特质判断散布到移动控制中。稀有条目必须同时声明 `Rarity=Rare`、`SourceRestriction=BossOnly`。未来 Boss 重复召唤的单位设置 `BuildRewardEligible=false`，防止刷捕食回血；现有 Boss 没有无限召唤单位。

`ActBuildRuntime.cs` 保存本局临时修正、形态继承、下一击强化、捕食值和已触发回血的房间记录；导出的 RunState 会复制这些数据。地图切换仅清理弹体、延迟骨雨、残影、震波等地图内对象，战技槽、进化、形态、异变、骨片、HP 和仍有效的临时强化持续保留。开始新的一局才清空本局数据。属性计算读取基础配置与当前形态、进化、异变、临时 Modifier，不写回玩家基础数值。

## 四章 Boss 配置

| 章节 | Boss | 招式 |
| --- | --- | --- |
| 1 | 暴君 · 苇海霸主 | 冲锋、尾扫、震地；复用原始资产并增加骨冠和连续步态 |
| 2 | 岩脊 · 裂谷甲兽 | 甲壳翻滚、尾锤、预警落石 |
| 3 | 羽镰 · 树冠猎主 | 跃袭、扇形飞羽、根刺；可跃上树枝平台 |
| 4 | 烬冠 · 熔炉之王 | 连续火焰、连锁地裂、跃地冲击与延迟喷发 |

四章 Boss 的最终生命为 24/42/64/72（含章节倍率），半血后加快节奏并增加落石、弹幕或地裂数量。危险区先预警，条带间保留躲避空间；Boss 死亡后清除残留弹体和危险区，留下进化与形态奖励点。

F10 地图调试中勾选“直接进入本章 Boss 场地”即可快速测试。主要参数集中在 `desktop/ActBosses.cs` 的 `ActBossCatalog`，新立绘与动作在 `desktop/ActBossVisual.cs`，暴君基础资产在 `desktop/PixelSprites.cs`。修改后运行 `build-exe.ps1` 重新打包。

双击项目根目录的 `恐龙冲刺.exe` 启动 Windows 单机游戏，不需要浏览器。从主界面选择“开始冒险”。四章之间固定进入安全的守夜营地；跨章保留本局 HP、骨片、战技和进化特质。也可以用右上角“地图调试”或 F10 直接选章验收。

区域采用晨雾湿地、芦苇沼泽、沉木栈道、迷雾林地、风蚀高地、古木荒原、碎岩谷地、失落遗迹、巨兽巢穴、曙光隘口等地名。每局首次进入区域时，名称短暂浮现后淡出；往返经过边界不会重复弹出。场景不再显示房间类型、测试区标签、倒 L 形边界标记或“清除敌人”封锁门。危险物和出口仍保留可见反馈。

| 动作 | 默认按键 |
| --- | --- |
| 左右移动 | A / D |
| 跳跃 | 空格：短按低跳、长按高跳 |
| 冲刺／闪避 | Shift：短距离冲刺，冲刺期间无敌，结束后冷却 |
| 三段爪击 | J：连续按下，第三击伤害与击退更高 |
| 尾扫 | K：双侧范围攻击，适合应对多敌人 |
| 空中踩踏 | S：空中快速下落并造成范围冲击 |
| 骨刺 | L：消耗 1 格远程能量 |
| 战技槽 1／2 | 1／2：使用并消耗对应战技 |
| 互动 | E：使用休息处设施或打开商人摊位 |
| 切换形态 | Q / R：上一个／下一个已获得形态，切换后冷却 5 秒 |
| 形态库 | F：查看并选择已获得的形态、查看异变记录 |
| 暂停／继续 | Esc |

点击“按键设置”可自行绑定全部动作，设置保存在根目录 `settings.json`。远程能量上限 5 格，每累计 2 次有效近战命中恢复 1 格；空挥、骨刺命中均不会回能。
敌人近身攻击即将命中时，面向敌人按爪击键可“拼刀”：抵消这次攻击、反击 1 点伤害，并使敌人短暂恍惚。成功时会出现交叉斩光、火花和屏幕震动。普通敌人恍惚约 0.72 秒，Boss 约 0.55 秒；远程弹幕、地面震波和环境伤害不能拼刀。判定范围与时间可在 `desktop/ActEnemies.cs` 的 `ActClashTuning` 中调整。
下砸命中或落地后有 0.5 秒跳跃恢复时间；恢复期间的跳跃按键不会缓存在结束后自动触发。

章节 Boss 倒下后仍需触碰尸体上的进化奖励点，并可领取额外的原始形态奖励。随后进入出口门附近并停留 3 秒，画面渐出至黑色，再以黑白渐入进入固定的章节间守夜营地；离开出口范围会取消计时。营地没有敌人和环境危险。火堆必定出现，按互动键可恢复最大 HP 的约一半，每个营地只能使用一次。另有 1～2 个随机设施，可能是商人、战技／进化奖励、骨片补给或异变龙蛋。异变龙蛋只在两张地图之间的营地出现。商人随机出售 3 件商品，骨片不足、已售出或已拥有的进化会明确提示；战技满槽时可选择替换。营地尽头的出口同样需要停留 3 秒，再进入下一章。第四章之后的营地出口结束本次远征。

骨片在本局内由敌人掉落及部分支路奖励获得，可在商店消费并跨章保留。开始新的一局时骨片清零。骨片掉落、设施出现率、火堆恢复量及商品价格集中在 `desktop/ActRestStop.cs` 的 `ActRestTuning` 中调整；章节切换不会自动恢复满血，已有进化特质的跨图回血效果仍然生效。

异变龙蛋提供三项不同的代价与收益，只能选择一项。本局异变持续到新开一局；“下一张地图”异变在营地获得时等待，进入下一张地图后生效，到进入再下一处营地时移除。原始形态从 Boss 额外奖励获得；基础形态始终保留，新开一局清除额外形态及异变。主要配置在 `desktop/ActPrimalCatalog.cs`，章节敌人倍率与增援比例在 `desktop/ActPrimalSystems.cs`。第二章敌人基础生命为第一章的 1.5 倍，第三、四章为 2 倍；后续章节逐步提高攻击欲望与部分安全遭遇中的敌人数量。

游戏画面与按键绑定窗口禁用输入法组字，中文输入法开启时也按原始按键操作，无需手动切换英文；不会修改系统默认输入法。键盘消息解码另对输入法转发的按键提供兼容处理。

### 历史连续地图（仅保留用于回归测试）

下面三段记录旧连续地图生成器。正式游戏和 F10 调试入口均使用前文所述的四章房间流程，不会生成这些旧大地图或战场间推进门。

教学地图保留固定的起点、主要地标、推进门、三角龙首领和终点；中段 4 个位置各有 3 个手工房间版本，每局由 Seed 选择。房间可能改变平台路线、敌人组合、尖刺／喷口／落石危险和奖励；两处额外栈道也可能开放。主流程始终可通行；标记为上层路线的房间会封闭下层，玩家需借已配置的平台越过墙体。两条额外栈道即使都未出现，也不影响通关。远程敌人蓄力后发射可躲避的弹体；飞行敌人预警后俯冲并重新升空；重型敌人蓄力冲锋后进入硬直。首领以冲锋、尾扫、震地三招轮换，半血后加快出招。部分推进门需要先击败前一区域的敌人；首领被击败并领取进化奖励后终点门打开。

风蚀峡谷使用固定入口、中段低谷、首领前缓冲区和六个随机节点。每个节点有两套手工地形，共 64 种组合：山坡攻防或双层裂谷、沉岩洞穴或断脊石桥、回旋高地或下层采石场、赤岩脊或双裂谷、风口高鞍或沉岩栈道、长谷断桥或梯田突进。坡顶远程敌人、下层近战敌人、空中敌人及少量环境危险随地形搭配；补给和奖励位置也随地表改变。主路线可用基础跳跃通过；较大的断层需要利用连续跳台，双层裂谷可以选择上下层路线。深坑会扣血并送回最近的安全地面，普通坑可跳过，下层低谷可走出。六个节点采用统一的入口和出口高度，因此组合后仍连通。第二章的薄跳台可从下方穿过，并能从上方落脚；连续坡面整体绘制，移动镜头时不会在地形接点露出亮线。

随机敌人从 8 组预设组合中选择，受早期 2～3、中期 4～5、后期 6～7 的威胁预算限制。清除房间敌人后才可领取该房间奖励。第一段房间固定给出战技奖励点；后续部分补给、攻击增强、移速增强奖励点也可能变成战技奖励，捷径可出现额外战技点。触碰“三道爪痕＋中央爆发”徽记后暂停，从随机 3 项战技中选 1 项。战技槽最多 2 个，满槽时选中战技后指定替换槽，也可放弃。Boss 死亡后在尸体中央留下 DNA 进化奖励点；倒地约 0.9 秒后可触碰领取，死亡本身不会弹窗。奖励点一直保留到领取或离开当前地图。拾取后从尚未拥有的进化特质中选 1 项。地图布局在开局时一次生成；死亡或通关后正常重新开始会生成新 Seed。

### 现有战斗与奖励界面

奖励选择界面覆盖在暂停的场景上，采用半透明切角卡片。战技界面使用骨金色爪痕纹样，进化界面使用青绿色 DNA 双螺旋。打开时约 0.32 秒渐入，选定后约 0.24 秒渐出，动画结束才恢复游戏。数字 1／2／3 或左右方向键＋回车可选择；战技满槽时选定新战技，再按 1／2 指定替换槽，Esc 放弃。回血奖励和固定补给改用鸡腿徽记，能量为骨刺簇，移速为羽翼，其余奖励采用对应战斗／进化图案。

战技共有再生孢子、骨甲、原始狂暴、时滞琥珀、骨刺风暴、地震咆哮、能量回流、狩猎本能。它们是一次性主动能力；原始狂暴、时滞琥珀、狩猎本能与骨甲的剩余时间或次数显示在左侧 HUD。进化特质共有锋利前爪、强壮尾骨、空心骨骼、雷鸣足骨、双生骨刺、猎手本能、厚重鳞片、再生组织。已获得特质在右侧显示图标，鼠标悬停可看名称和说明；同一种特质本局只能获得一次。再生组织在进入风蚀峡谷时触发回血。

玩家与敌人受到攻击时有短暂命中停顿、闪烁、粒子和击退；重攻击震动更明显。HP 耗尽后播放短暂死亡表现，再显示重新开始。到达终点后显示通关时间、击败敌人数和剩余 HP。

两张地图的固定补给均已改为独立营地，用遮棚、暖色篝火、绿植、水盆和食物篮与战斗空间区分。第一张地图有 4 处营地；第二张地图长度为 21800 个关卡单位，是上个版本的两倍，六个战斗节点之间有 5 处营地，入口和出口以缓坡连接战斗地形。每处补给本张地图只能取用一次，恢复 2 HP（不超过上限）并补满骨刺能量；两者全满时不会消耗补给。进入营地后敌人停止追击并返回原区域，剩余敌人血量与击败进度保留；敌方弹体不能穿过营地。已取用的营地仍保留场景，并显示空篮与取用状态。

### 第三、四章旧连续地图配置

以下旧长度、长桥和营地布置仅用于历史地图回归。正式房间模板位于 `ActChapterRoomThemes.cs`，每章仅经过 4～5 个小房间；机关周期、单向平台、地形救援和主题渲染继续复用下列组件。

- **巨木秘境**：32700 关卡单位（峡谷的 1.5 倍）。7 个手工节点，随机开放树冠高路、浅层林地或地下树根通道，最终汇合。配有升降台、横移台、踩踏后延迟坠落并恢复的平台，以及无需新技能的弹性蘑菇。3 处独立树荫营地；首领场地保留多层平台。
- **熔火遗迹**：43600 关卡单位（峡谷的 2 倍）。9 个节点，其中一段为约 12 秒的崩塌长桥；其余节点在手工地形上随机使用喷发、落石或移动跳台配置。岩浆掉落扣血并回到最近安全地面。4 处冷岩营地；首领场地只有一处有预警的喷发，不叠加落石。
- 动态攻击采用 6 秒周期：2.5 秒后开始预警，3.8 秒开始作用，4.9 秒结束。同一轮喷发／落石最多命中玩家一次；落石也可伤害普通敌人。蓝绿色热气流用于向上移动，橙红色喷发造成伤害。

## Seed 调试

双击 EXE 后可随时点击右上角“地图调试”，或按 **F10** 打开地图选择界面。可直接进入全部四章，输入正整数 Seed 复现布局，或勾选“随机生成新布局”。“保留本局 HP、战技和进化特质”默认关闭；勾选后切换地图会保留这些能力，敌人、补给、关卡计时及出生位置仍重新生成。确认后直接开始所选地图；从战斗中打开界面会先暂停，取消选择后保持暂停。

需要查看完整房间组合信息或用 F8／F9 测试奖励时，可在 PowerShell 中输入以下命令启动扩展 Debug 模式：

```powershell
& "G:\CODEX\DINO\恐龙冲刺.exe" --debug --seed 12345
```

扩展 Debug 模式会在底部显示 Seed 和所选房间；点击该行可查看完整房间／敌人／危险／奖励／捷径信息。死亡或通关后，“同种子重开”会复现本局布局；普通“重新开始”生成新布局。生成摘要也写入 .NET Trace 输出，便于附加调试器排查。

扩展 Debug 模式下，在游戏运行中按 **F8** 可直接打开战技三选一，按 **F9** 可直接打开进化特质三选一。地图选择按钮和 F10 在普通模式中也可使用。

powershell -NoProfile -ExecutionPolicy Bypass -File "G:\CODEX\DINO\build-exe.ps1"
